Aide

Mise à jour automatique

  1. Une seule fois : menu ⋮ › Activer la mise à jour automatique, puis saisissez le mot de passe d'équipe donné par le gestionnaire des données.
  2. Ensuite, à chaque ouverture (avec Internet), l'application récupère les dernières données publiées depuis l'ordinateur. Le bouton ⟳ en haut force la vérification.
  3. Sans Internet, les dernières données reçues restent affichées. Si l'en-tête devient jaune, les données ont plus de 2 jours.

Sans Internet ni mot de passe

  1. Recevez le classeur .xlsx (WhatsApp, câble…) puis ⋮ › Ouvrir un fichier Excel, ou Partager › Suivi MVE.

Installer l'application

  1. Ouvrez l'adresse de l'application dans Chrome sur Android.
  2. Menu ⋮ › Installer l'application (ou « Ajouter à l'écran d'accueil »).
  3. L'icône « Suivi MVE » apparaît avec les autres applications. Elle fonctionne ensuite sans connexion.

Confidentialité

Les données publiées sont chiffrées ; le mot de passe d'équipe ne doit pas être partagé hors de l'équipe. Effacez les données depuis le menu avant de prêter ou de changer de téléphone.
