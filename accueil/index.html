Mettre les tableaux de bord à jour

  1. Ouvrez le classeur dans Excel, puis Données › Actualiser tout.
  2. Enregistrez le classeur (Ctrl+S) dans le dossier ci-dessus.
  3. Le tableau de bord se recharge tout seul dans la minute (ou dès que vous revenez sur sa fenêtre).

Les fichiers sont reconnus par leur nom : « Tableau_de_bord_MVE », « …Qualite_Donnees_MVE », « …Vaccination… », « …Contacts… » et « …Qualite_Donnees_Contacts… ». Si plusieurs fichiers du même type sont présents, le plus récent est utilisé. Aucune donnée ne quitte l’ordinateur.
